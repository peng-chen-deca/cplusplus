# C++ 学习笔记

这是一个用于学习和实践 C++ 的个人代码仓库，重点关注现代 C++ 特性以及游戏服务器开发。

## 关于本项目

本仓库用于记录我的 C++ 学习过程，包括语言基础、高级特性、实践示例以及服务器端编程相关内容。

学习目标是建立扎实的 C++ 编程基础，并将所学知识应用到实际的游戏服务器开发中。

## 学习内容

### 1. C++ 基础
- 变量与数据类型
- 运算符与流程控制
- 函数与引用
- 指针与内存管理
- 类与对象
- 继承与多态

### 2. 现代 C++
- C++11/14/17/20 新特性
- 智能指针
- 移动语义
- Lambda 表达式
- 模板与泛型编程
- STL 容器与算法

### 3. C++ 进阶
- 内存管理
- 多线程与并发编程
- 同步机制与线程安全
- 性能优化
- 设计模式

### 4. 游戏服务器开发
- TCP/UDP 网络编程
- Socket 编程
- 异步 I/O
- 多线程服务器架构
- 游戏服务器架构设计
- 高性能服务器开发

## 开发环境

- 编程语言：C++
- 语言标准：C++17 / C++20
- 编译器：GCC / Clang
- 构建工具：CMake
- 开发工具：Visual Studio Code / CLion

## 学习目标

- 掌握 C++ 核心概念与现代 C++ 特性。
- 理解内存管理机制与性能优化方法。
- 具备开发多线程及网络应用程序的能力。
- 探索可扩展的游戏服务器架构设计。
